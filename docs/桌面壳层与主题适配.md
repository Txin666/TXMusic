# 桌面壳层与浅色主题适配记录

## 1. 无边框窗口与自绘标题栏

| 项目 | 实现位置 | 说明 |
| --- | --- | --- |
| 去掉系统标题栏 | `lib/main.dart` | `WindowOptions.titleBarStyle = TitleBarStyle.hidden` |
| 自绘标题栏 | `lib/shared/widgets/window_title_bar.dart` | 拖动区（`startDragging`）、双击最大化、最小化/最大化切换/关闭按钮，hover 变色，颜色取自 `context.palette` 以适配深浅色 |
| 全局叠加 | `lib/shared/widgets/app_window_frame.dart` | 通过 `MaterialApp.router` 的 `builder` 统一包裹，所有路由自动生效；标题栏高 36（`AppSpacing.titleBarHeight`），不遮挡顶部搜索栏 |

标题栏按钮的 Tooltip 已移除（`MaterialApp.builder` 层在 `Navigator` 之外，没有 `Overlay`，`Tooltip` 会抛 `No Overlay widget found`），改用 `Semantics(label:)` 保留无障碍标签。

## 2. 关闭最小化到托盘

- `DesktopHost.attachWindow()`：`windowManager.setPreventClose(true)` + `WindowListener`。
- `onWindowClose()` → `hideToTray()`：仅 `hide()`，进程与播放继续，并弹 SnackBar「已最小化到托盘，仍在后台播放」。
- 只有托盘菜单「退出 TX Music」走 `quitApp()`：先 `TrayIcon.dispose()` / 菜单释放，再 `windowManager.setPreventClose(false)` + `destroy()`。

## 3. 系统托盘

`lib/core/desktop/desktop_host.dart`，依赖 `tray_manager: ^0.8.3`（nativeapi 0.5.x API）：

- 图标：`assets/icons/tray.ico`（复制自 `windows/runner/resources/app_icon.ico`，`pubspec.yaml` 已声明 assets）。
- 菜单：显示主窗口 / 播放/暂停 / 上一首 / 下一首 / 退出 TX Music。
- 左键点击 `TrayIconClickedEvent` → `show()` + `focus()`；右键由 `setContextMenuTrigger(ContextMenuTrigger.rightClicked)` 绑定（Windows 默认不自动弹菜单）。
- 播放控制回调在 `AppWindowFrame` 注入，实际调用 `playerController.togglePlayPause()` / `skipPrevious()` / `skipNext()`。
- 所有原生调用均 `try/catch`，`flutter test`（`FLUTTER_TEST=true`）下 `DesktopHost.isSupported == false` 直接短路，不影响既有测试。

## 4. 浅色主题修复

- 新增 `lib/theme/app_palette.dart`：`ThemeExtension<AppPalette>`，语义色包含 background / surface / surfaceAlt / surfaceHigh / divider / textPrimary / textSecondary / textDisabled / hoverOverlay / scrim，提供 `context.palette` 扩展。
- `AppTheme._build` 为深色注入 `AppPalette.dark`（等于原 `AppColors` 深色常量，观感不变），浅色注入 `AppPalette.light`（#F6F6FA 底 / #FFFFFF 卡片 / #17171C 文字）。
- 组件层 148 处 `AppColors.background|surface|surfaceAlt|surfaceHigh|divider|textPrimary|textSecondary|textDisabled` 硬编码引用已全部替换为 `context.palette.*`；品牌色 primary / secondary / accent / danger 仍直接取 `AppColors`。
- 校验：`test/theme_palette_test.dart` 断言两套主题扩展注入正确，且正文对背景对比度 ≥ 4.5。

## 5. 顺带修复

- `discover_banner_carousel.dart` 卡片内容在 176 高度下溢出 24px：轮播高度调至 188，卡片内边距 `xl → lg`、纵向间距 `md → sm`、`lg → md`。
